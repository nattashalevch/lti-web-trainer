# LTI-тренажёр: HTML и CSS (три задания)

Инструмент LTI 1.3 для Moodle. Студент отвечает на три вопроса, сервер сам считает баллы (максимум 10) и отправляет оценку в журнал курса через AGS.

Стек: Node.js, ltijs, MongoDB (хранит регистрацию LTI и ключи), файл `data/attempts.json` (попытки студентов).

## Локальный запуск

```
npm install
cp .env.example .env
docker compose up -d mongo
npm test
npm start
```

Проверка: `http://localhost:3000/healthz` возвращает `{"ok":true}`. Страница `/app` без запуска из Moodle недоступна (401), это нормально.

## Деплой на Render

1. Создайте бесплатную базу MongoDB Atlas, скопируйте строку подключения `mongodb+srv://...`.
2. На Render: New → Web Service → ваш GitHub-репозиторий, окружение Docker.
3. Переменные окружения: `MONGO_URL`, `LTI_KEY` (любая длинная строка), `MOODLE_URL`, `MOODLE_CLIENT_ID` (последние два пока пустые).
4. Откройте `https://<сервис>.onrender.com/healthz`.

## Регистрация в Moodle

Администрирование → Плагины → Модули → Внешний инструмент → Управление инструментами → «настроить инструмент вручную».

| Поле | Значение |
|---|---|
| URL инструмента | `https://<сервис>.onrender.com/lti/launch` |
| Версия LTI | LTI 1.3 |
| Тип открытого ключа | Keyset URL |
| URL набора открытых ключей | `https://<сервис>.onrender.com/lti/keys` |
| URL инициации входа | `https://<сервис>.onrender.com/lti/login` |
| URI перенаправления | `https://<сервис>.onrender.com/lti/launch` |
| Службы | Assignment and Grade Services: использовать для отправки и чтения оценок |
| Конфиденциальность | передавать имя пользователя |

После сохранения откройте «Подробности инструмента» и скопируйте Client ID. Вставьте его в `MOODLE_CLIENT_ID` на Render, а в `MOODLE_URL` адрес вашего Moodle без слэша на конце. Перезапустите сервис.

Если ваш Moodle показывает другие адреса (authentication / access token / keyset) в подробностях инструмента, задайте их в `MOODLE_AUTH_URL`, `MOODLE_TOKEN_URL`, `MOODLE_JWKS_URL`.

## Элемент курса

В курсе: Добавить элемент → Внешний инструмент → выберите ваш инструмент. Максимальная оценка 10, запуск в новом окне. Откройте элемент под тестовым студентом (записанным на курс). Ответьте, нажмите «Проверить и отправить в Moodle» и проверьте журнал оценок.

## Безопасность

- Правильные ответы остаются на сервере.
- Пользователь, роль и курс берутся из проверенного запуска LTI, а не из браузера.
- Не публикуйте `.env`, `data/`, ключи и пароли.
- Бесплатный Render очищает диск при перезапуске, поэтому история попыток может сброситься; регистрация и ключи хранятся в MongoDB и сохраняются.
